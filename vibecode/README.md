# Gallery Book Website

Website gallery book yang elegan dan modern untuk pasangan Anda.

## Fitur

- ✨ Design minimalist dan modern
- 🎨 Warna pastel elegan (soft pink, lavender, peach)
- 📱 Responsive design (mobile-friendly)
- 🖼️ Gallery dengan lightbox
- ✨ Animasi smooth scroll dan fade-in
- ⌨️ Navigasi keyboard untuk lightbox
- 🎯 Smooth scrolling effects

## Cara Menggunakan

1. **Ganti Foto**: Edit file `script.js` dan ganti array `galleryImages` dengan URL foto Anda:
   ```javascript
   const galleryImages = [
       {
           src: 'path/to/your/image1.jpg',
           alt: 'Deskripsi foto 1'
       },
       // ... tambahkan foto lainnya
   ];
   ```

2. **Buka Website**: Buka file `index.html` di browser Anda

## Customization

- **Warna**: Edit variabel CSS di `style.css` bagian `:root`
- **Font**: Font saat ini menggunakan Google Fonts (Playfair Display & Inter)
- **Jumlah Foto**: Tambah/kurangi item di array `galleryImages`

## Browser Support

Website ini bekerja di semua browser modern (Chrome, Firefox, Safari, Edge).
